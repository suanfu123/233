# Minecraft 1.16.5 · 网页版

用 **原生 WebGL2 + JavaScript** 实现的 Minecraft 1.16.5 复刻版，
**直接使用资源包 `assets/` 中的原版贴图、模型与 blockstate 数据**，
方块外观、植物交叉模型、楼梯/台阶/栅栏/火把等几何都由原版 JSON 真实解析生成。

## 快速开始

**必须通过本地 HTTP 服务打开**（浏览器禁止 `file://` 页面读取贴图，双击 index.html 会报错）。

```
双击 start.bat
```

然后浏览器访问 <http://localhost:8080/>

`start.bat` 会自动优先使用 Node，其次 Python。也可以手动运行：

```bash
node server.js 8080        # 或
python -m http.server 8080
```

macOS / Linux 用户可以直接运行 `node server.js` 或 `python3 -m http.server 8080`。

> 首次加载需要读取 408 张贴图，通常 1~3 秒。

### 调试参数（URL）

在地址后追加 `?d=参数;参数`，多个参数用 `;` 分隔（`0`/`1` 表示开关，其余为数值）：

| 参数 | 说明 |
| --- | --- |
| `frames:N` | 运行 N 帧后停止主循环（便于截图与自动化验证） |
| `selfcheck:1` | 遍历全部方块变体，校验模型几何 / 贴图索引是否一致，结果写入 `window.__selfcheck` |
| `bench:1` | 在固定坐标生成并网格化 16 个区块，输出 `genAvg` / `meshAvg`（毫秒）到 `window.__bench` |
| `autotest:1` | 自动跑一遍「射线拾取 → 破坏 → 放置 → 光照 → HUD / 物品栏点击」，结果写入 `__diag.autolog` |
| `scene:1` | 在出生点旁摆放一圈测试方块（楼梯 / 台阶 / 玻璃板 / 火把 / 灯笼…） |
| `pos:x,y,z` `pitch:` `yaw:` `time:` `seed:` | 固定相机位置、朝向、时间、种子 |
| `rd:N` `fly:1` `screen:game\|inventory` `hidehud:1` | 渲染距离、飞行、初始界面、隐藏 HUD |

页面每 500ms 把运行状态写入隐藏的 `#diag` 元素（pos / chunks / draws / tris / fps / glErr / self / bench 等），可直接用于 headless 抓取。

## 已实现的内容

**世界**
- 16×16×384 区块，按距离分帧加载/卸载，视锥剔除
- Simplex 噪声地形：大陆、山脉、丘陵、细节噪声
- 20 种生物群系（平原/森林/白桦林/针叶林/雪原/沙漠/热带草原/丛林/沼泽/山地/恶地/蘑菇岛/海洋/深海/冻洋/沙滩/雪滩/石岸…）
- 洞穴（3D 噪声交叉隧道 + 空腔）、深层岩浆湖、基岩层
- 9 种矿物按深度分布（煤/铁/金/钻石/红石/青金石/绿宝石/下界金/石英）
- 5 种树木（橡木/白桦/云杉/丛林/金合欢）+ 树苗、草丛、花卉、仙人掌、甘蔗、蘑菇、海草、海带
- 平滑光照：天空光 BFS 传播 + 方块光（火把/萤石/海晶灯/灯笼/岩浆）
- 环境光遮蔽（AO）与方向性明暗
- 生物群系染色：草/树叶颜色来自原版 `colormap/grass.png`、`foliage.png`（与原版公式一致）
- 昼夜循环（20 分钟一天）、太阳/月亮/星空、流动的云层、雾效、水下滤镜

**方块**
- 301 种方块，几何全部由原版 `models/block/*.json` + `blockstates` 解析（含 parent 继承、`#texture` 变量、multipart、变体旋转、元素旋转与 rescale）
- 完整支持：完整方块、台阶、楼梯、栅栏、墙、铁栏杆、玻璃板、门、活板门、火把、灯笼、告示牌类交叉模型、柱状（原木/玄武岩/锁链）、十字植物
- 放置朝向：楼梯/熔炉/箱子朝向玩家，原木按点击面决定轴向，台阶可放上半/下半
- 破坏进度覆盖层（`destroy_stage_0~9`）
- 水/岩浆使用原版 32/20 帧动画贴图
- 手持方块以第一人称渲染

**渲染**
- 动态纹理数组：自动检测 GPU 支持的 `MAX_ARRAY_TEXTURE_LAYERS`，最多 4 个 `sampler2DArray`（每层 256，共 1024 层），承载 408 张贴图，无图集接缝、支持 mipmap
- 每区块合并网格 + 面剔除 + AO，不透明/半透明双批次
- 片元着色器内置光照曲线、雾、生物群系染色、水面动画

**界面（Canvas2D，全部使用原版 GUI 贴图）**
- 原版 `ascii.png` 位图字体（自动测量字宽、阴影、`§` 颜色代码）
- 快捷栏 / 选中框 / 物品数量 / 物品名提示
- 创造模式物品栏：5 个分类、等轴测方块图标、悬停名称、滚轮翻页
- 暂停菜单、选项（渲染距离 / FOV / 灵敏度 / 亮度 / 界面缩放 / 全屏）
- F3 调试屏、聊天栏、Toast 提示、死亡界面、生命值显示

## 目录结构

```
index.html                入口
css/style.css             加载界面与画布样式
server.js                 零依赖静态服务器
start.bat                 一键启动
assets/                   原版资源包（未改动）
  minecraft/              贴图 / 模型 / blockstates / 语言 / 字体
  generated/blocks.js     ← 由构建脚本生成（方块表 / 模型 / 贴图索引）
src/
  core/util.js            数学库 / Simplex 噪声 / 随机数
  core/glutil.js          WebGL2 封装（着色器、VAO、纹理数组、视锥体）
  core/textures.js        贴图加载 → 纹理数组 / GUI 图集 / 色图
  core/font.js            原版位图字体渲染
  world/blocks.js         方块注册表 + 模型几何生成（含旋转/rescale）
  world/worldgen.js       生物群系 / 地形 / 洞穴 / 树木 / 矿物
  world/chunk.js          区块数据 / 光照 BFS / 网格生成（AO + 平滑光照）
  world/world.js          区块调度 / 方块读写 / 网格上传
  render/sky.js           天空 / 太阳月亮 / 星空 / 云
  render/renderer.js      区块渲染 / 选中框 / 破坏进度 / 手持方块
  player/player.js        物理碰撞 / 射线拾取 / 放置朝向
  ui/hud.js               HUD / 物品栏 / 菜单 / 调试屏
  main.js                 启动 / 输入 / 主循环 / 指令
tools/build-assets.js     资源构建脚本（node tools/build-assets.js）
```

重新生成 `assets/generated/blocks.js`：

```bash
node tools/build-assets.js
```

它会校验每个方块引用的贴图是否存在，并输出统计信息。

## 性能

- 默认渲染距离 8 区块（可在选项中调到 2–24）
- 区块生成与网格构建按每帧 7ms 预算分帧执行，不会卡住主线程
- 移动端/核显建议渲染距离 4–6、关闭高 DPI

## 已知限制

- 资源包中没有音效文件，因此没有声音
- 仅实现原版方块的静态朝向（无红石逻辑、无方块实体、无生物）
- 生存模式为简化版：有挖掘时间、摔落伤害与生命值，但没有饥饿度、合成与掉落物实体
- 水体为静态高度（14/16），没有流动模拟
- 移动端触摸控制为基本实现，复杂操作（如精确放置）可能不便

## 更新记录

**重构（本次）**

- 修复方块几何缓存 key 碰撞：变体数超过 16 的方块（各类楼梯、橡木门、蜂巢、藤蔓等 14 种）会互相串用模型，表现为橡木台阶显示成紫珀、玻璃板/活板门缺失。缓存改为挂在方块定义上，按变体索引存放
- 光照由「只增不减」改为可消光（天空光/方块光各自做移除扫描 + 重新扩散），破坏遮挡方块后不会留下错误亮区；写方块时按实际变化决定重算范围，不再整块重算
- 世界生成：树冠跨区块时写入目标区块的待应用队列（原先在区块边界被截断）；岩浆湖限制在 y≤8 且加入噪声条件（原先 y<10 的空气几乎全变岩浆）；删除无效的矿脉调用
- 区块网格只遍历区块实际高度范围；每帧不再重新分配与排序区块需求列表
- 渲染路径复用矩阵对象，去掉每帧的临时数组分配
- `server.js` 增加 `ETag` / `304` 与 gzip 压缩（`blocks.js` 810KB → 68KB）
- 新增 `?d=selfcheck`（全变体几何/贴图一致性校验）与 `?d=bench`（生成/网格化耗时基准）
